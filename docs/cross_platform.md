# Cross-Platform Native Support

Nthgn is designed to run natively everywhere:
- **Desktop:** Native binaries for Windows (.exe), macOS, and Linux.
- **Mobile:** Native APKs for Android and iOS-compatible build targets.

## Build Commands
```bash
# Mobile/Desktop Native Only
flutter build apk
flutter build macos
flutter build windows
flutter build linux
```
*Note: Web/Browser targets have been removed per security-first requirements.*
