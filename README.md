# Nthgn - Private & Secure Messaging

Nthgn is a desktop-first, privacy-focused open-source messenger designed for total anonymity.

## How it's made
- **Core Engine:** Written in Rust using `libp2p` for distributed peer-to-peer networking.
- **Frontend:** Built with Flutter, offering a modern, session-style dark UI.
- **Privacy:** Integrates Tor routing directly into the networking layer.
- **Security:** End-to-end encrypted messaging by default.

## Installation
Run the following command to install the application:
```bash
./install.sh
```

## Privacy Settings
Toggle Tor routing and manage your session keys directly from the settings menu.
