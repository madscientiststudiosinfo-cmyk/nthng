# Nthgn: The Ultimate Private, Open-Source Encrypted Messenger

**Nthgn** is a cutting-edge, desktop-first, privacy-focused open-source messaging application designed for absolute anonymity. Built with security at its foundation, Nthgn ensures your digital conversations remain yours alone.

## Why Choose Nthgn for Private Communication?
- **Unrivaled Privacy:** Integrated **Tor routing** masks your IP address, ensuring total anonymity in every session.
- **Post-Quantum Security:** We utilize **Signal-grade E2EE** augmented with **Post-Quantum KEM (Kyber)** to future-proof your communications against emerging threats.
- **Zero-Metadata Policy:** Unlike mainstream apps, Nthgn stores **no metadata**—no timestamps, no read receipts, and no routing logs. Ever.
- **Cross-Platform Resilience:** A shared, high-performance Rust core ensures uniform security and speed across Windows, Linux, and macOS.
- **Self-Hosted Capability:** Run your own private messaging node within an isolated Docker environment.

## Key Technical Features
- **Core Engine:** Written in memory-safe Rust for maximum performance and security.
- **Networking:** Powered by `libp2p` for robust, decentralized peer-to-peer connectivity.
- **UI:** A modern, sleek Flutter-based dark interface tailored for power users.
